# Python Fundamentals

Python is a general-purpose programming language designed to make code readable. A Python program is made of statements, expressions, names, and blocks. Indentation defines blocks instead of braces, so consistent indentation is part of the program's syntax. Names refer to values, and assignment binds a name to a value; it does not copy an object automatically. Python is dynamically typed, which means a name can refer to values of different types over time, but each value still has a specific type such as `int`, `str`, `list`, or a user-defined class.

The basic built-in types cover common data: integers and floating-point numbers represent numeric values, booleans represent truth values, and strings represent text. Lists preserve order and can be changed in place. Tuples preserve order but are immutable. Dictionaries map unique keys to values, while sets store unique elements without a meaningful positional order. Use a list when order and updates matter, a tuple for a small fixed grouping, a dictionary for lookup by key, and a set for membership tests or uniqueness. Strings and tuples are immutable, so operations that appear to modify them produce new values.

Expressions combine values with operators. Arithmetic includes addition, subtraction, multiplication, division, floor division, modulo, and exponentiation. Comparisons produce booleans, and logical operators `and`, `or`, and `not` combine conditions. Python's `if`, `elif`, and `else` statements select which indented block runs. `for` loops iterate over items in an iterable such as a list or range; `while` loops repeat while a condition remains true. Prefer iterating directly over items rather than manually tracking indexes unless the index is needed. `break` exits a loop, and `continue` skips to its next iteration.

Functions package reusable behavior. Define one with `def`, give it parameters, and use `return` to send a result back to the caller. A function without an explicit return value returns `None`. Parameters can have default values, but mutable objects such as lists should generally not be used as defaults because the same object is reused across calls. Instead, default to `None` and create a fresh object inside the function. Functions should usually do one clearly described task, use meaningful names, and document non-obvious behavior. Local variables belong to the function call; avoid changing global state when a return value or an explicit object can carry the result.

Errors are represented by exceptions. A `try` block contains operations that may fail, and an `except` block handles a specific expected exception. Catching broad `Exception` without a clear recovery plan can hide programming mistakes. Use `raise` to signal invalid input or an unmet condition, and preserve useful context in error messages. Files should be opened with a context manager such as `with open(path, encoding="utf-8") as file:` so they are closed reliably, including when an error occurs. The same `with` pattern is used by resources such as database connections.

Modules are Python files that can be imported. Put reusable code in functions or classes, and protect script-only behavior with `if __name__ == "__main__":` so importing the module does not unexpectedly run the program. The standard library provides useful modules for paths, dates, JSON, collections, and testing. A virtual environment isolates a project's installed packages from other projects; dependency declarations help another developer recreate the environment. Good fundamentals also include testing small units, formatting consistently, and reading tracebacks from the bottom upward to locate the exception and the line that caused it.
