# AI Foundations

Artificial intelligence is a broad field concerned with systems that perform tasks associated with perception, reasoning, language, planning, or decision-making. It includes rule-based programs as well as systems that learn patterns from data. Machine learning is a major area within AI: instead of writing every decision as a fixed rule, a developer chooses a learning method and provides examples or feedback from which a model estimates useful patterns. The model is an artifact produced by training; an algorithm is the procedure used to produce or apply it.

In supervised learning, examples contain inputs and target labels or values. Classification predicts a category, such as a message being spam or not spam. Regression predicts a numeric quantity, such as a price estimate. In unsupervised learning, examples lack target labels; clustering can group similar examples, while dimensionality reduction can represent complex data with fewer variables. Reinforcement learning studies an agent that takes actions in an environment and receives rewards or penalties. These settings answer different questions, so selecting a method begins with defining the task and the available data rather than choosing a popular model first.

A dataset is commonly separated into training, validation, and test portions. The training set fits model parameters. The validation set helps choose settings, compare candidate approaches, or decide when to stop training. The test set estimates performance on examples held back from those decisions and should not be repeatedly used to tune the system. Data leakage occurs when information unavailable at real prediction time influences training or evaluation, producing misleadingly strong results. Splits should reflect the way the system will be used; for example, time-dependent data may need chronological splits rather than random ones.

Model quality needs measures that fit the consequences of errors. Accuracy is the share of predictions that are correct, but it can be deceptive when classes are imbalanced. Precision asks what fraction of predicted positives are truly positive; recall asks what fraction of actual positives are found. A false positive and a false negative may have very different costs in a particular application. Regression measures include mean absolute error and mean squared error, which emphasize errors differently. Metrics summarize behavior on a sample and do not prove that a system is fair, safe, or useful for every user.

Overfitting describes a model that matches training examples too closely and performs poorly on new data. Underfitting describes a model too limited to capture useful patterns even in its training examples. More representative data, appropriate regularization, simpler models, better features, or changed training settings can help, but the right remedy depends on diagnosis. A baseline is an intentionally simple approach that provides a reference point. A complex system should demonstrate a meaningful improvement over a baseline on an evaluation that reflects actual use.

AI systems are socio-technical: results depend on data collection, objective choices, interfaces, human decisions, and operating conditions, not just a model. Training examples may encode historical bias or omit important groups. A responsible project documents intended use, limitations, data provenance, evaluation methods, and known failure modes. Monitor performance after deployment because incoming data and user behavior can change. Provide appropriate human review and a way to report failures when decisions are consequential. AI output is a prediction or generated response, not automatically a fact; verification, privacy protection, security testing, and clear accountability remain necessary.
